Download WedgeScope ZIP
  1. Install standard 64-bit Python 3.13 and extract the whole ZIP.
  2. Open Start WedgeScope.cmd on Windows or Start WedgeScope.command on Mac. Your first launch registers this computer to your invite. Ask the owner for a reset code when switching computers.
  3. Open Robinhood in the local dashboard, connect your account, then choose Robinhood → Save and scan in Scan settings.

The running scanner checks for updates and saves new ZIPs to your Downloads folder.
